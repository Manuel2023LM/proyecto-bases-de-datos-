# Material fuente compartido por el equipo

Estos archivos se conservan como referencia de los insumos recibidos del equipo; no reemplazan los scripts finales que usa la aplicación.

- `censo_terremoto_postgresql.sql`: esquema fuente previo a la integración.
- `censo_terremoto_datos_prueba.sql`: población de prueba fuente.
- `vistas_censo_terremoto.sql`: vistas fuente.
- `Guia_tecnica_censo_terremoto.docx`: guía técnica recibida.

Los scripts integrados y probados para esta entrega están en [`../../sql/00_proyecto_completo.sql`](../../sql/00_proyecto_completo.sql), [`../../sql/01_esquema_censo_terremoto.sql`](../../sql/01_esquema_censo_terremoto.sql), [`../../sql/02_datos_ficticios.sql`](../../sql/02_datos_ficticios.sql) y [`../../sql/03_vistas_censo_terremoto.sql`](../../sql/03_vistas_censo_terremoto.sql). El archivo `Relational_1.pdf` recibido es idéntico al diagrama conservado como [`../diagrama_relacional_base.pdf`](../diagrama_relacional_base.pdf), por lo que no se duplica.
